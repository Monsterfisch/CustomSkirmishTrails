Export writes every mission line of the Warchest trail's csv files into a JSON file of its own, in a folder named like the csv file next to it. Import puts those JSON files back together into the csv files.

The game does the work: choose a button, press Save and close, then start the game once. With several csv files for different languages, all of them are converted.

Make language text files: turns the language csv files into one text file per language (texts/<language>.json next to the default csv), plus texts/_template.json for translators. A language csv whose gameplay data differs from the default csv is reported and left out.
